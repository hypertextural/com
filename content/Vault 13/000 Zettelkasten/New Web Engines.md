# New Web Engines

Links: [[Web Engines]]

Check out servo, ladybird and flow—these are new browsers, not based on WebKit or V8.

**Servo**: [[Rust]] based embedded web rendering engine. Aim is to allow using web tech in embeddable application. 
https://servo.org/

**Ladybird**: Part of the [SerenityOS](https://github.com/SerenityOS/serenity) project. Scratch browser.
https://ladybird.dev/

**Flow**: Built for Televisions, interestingly. Uses SpiderMonkey.
https://www.ekioh.com/flow-browser/
