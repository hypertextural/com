# Backwards Compatibility of Web Tech is Advantageous to Slow, Complex Organizations

Links: [[Backwards Compatibility]], [[Government Tech]]

The web platform is backwards compatible and that is a boon to a slow moving org like the federal gov. Having fed employees update react apps sounds like a path to brokenness, for example.

The stability affords greater resilience by staving off [[bit rot]].
