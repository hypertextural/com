To set global keyboard shortcuts for my window manager, I use [skhd](https://github.com/koekeishiya/skhd "skhd hotkey daemon for macOS") and [Karabiner-Elements](https://karabiner-elements.pqrs.org/ "Karabiner-Elements keyboard customizer for macOS") alongside [GokuRakuJoudo](https://github.com/yqrashawn/GokuRakuJoudo "GokuRakuJoudo configurator for Karabiner-Elements"), a tool that makes writing the configuration file for Karabiner much less tedious. I created a [GitHub repo containing all my macOS shortcuts and configurations](https://github.com/leonsilicon/macos-configs "leonsilicon's macOS config repo"), which serves as a convenient source of truth and reference for when I want to create a new shortcut.
