# Citations in Markdown

Links: [[Citations]], [[Markdown]]

Check out [[Obsidian Plugins]], and [[Zotero]]

> 1. Citations and book references are added via the extended MultiMarkdown syntax. It connects beautifully with BibTeX, which is a widely-supported format to save bibliographic data in plain text files. Our recommendation for Mac is the open-source tool [BibDesk](https://bibdesk.sourceforge.io/) and for Windows [JabRef](https://jabref.org/) to manage the bibliographical data and connect it to the Zettelkasten via the citekeys it produces.
